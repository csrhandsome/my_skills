# 行业信号如何挂钩本周工作

在已经写出「这周已做 / 下周待做」，并且 `embodied-weekly-brief` 已经出完整行业周报之后，再写这一段。

## 工作焦点

从上一步的工作正文抽取 3–6 个主题。常见别名见 `config.yaml` 的 `project_aliases`，例如：

- 数据平台 / 竞品 / 报价 / 设备管理
- 数据集 / 外采 / 路径 / OSS 下载
- 自动化标注 / 质检 / 数据集生成 PRD
- Tidel AI / 标定 / hand tracking / 夹爪

表里出现的新主题也要收进焦点，不要只认这份名单。

## 「和我工作的关系」怎么写

只写**对得上**的信号，每条包含：

1. 行业信号一句话（公司/事件）
2. 对上我的哪条工作（数据平台、标注、数据集…）
3. 对我意味着什么（竞品要补什么、下周可以盯什么），不编造待办

格式：

```text
1.信号：和「主题」有关。启示：……
```

3–5 条即可。行业头条里和当前工作无关的，留在「行业动态」，不要硬写进这一段。

## 不要做

- 不要因为「都是机器人」就把所有新闻挂到数据平台上
- 不要把「和我工作的关系」写成第二份行业周报
- 不要把挂钩出来的动作写进「下周待做」，除非用户工作表里本来就有
