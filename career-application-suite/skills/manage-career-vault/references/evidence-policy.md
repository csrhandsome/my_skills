# Career Vault Evidence Policy

## Fact classes

Use one of these classes for every statement:

- `VERIFIED`: directly confirmed by the user and supported by a source or concrete recollection.
- `USER_CONFIRMED`: confirmed by the user but no durable artifact is available.
- `INFERRED`: reasonable interpretation that must not appear as fact until confirmed.
- `UNKNOWN`: unresolved.

Only `VERIFIED` and `USER_CONFIRMED` facts may be used in a resume. Mark `INFERRED` and `UNKNOWN` items as questions.

## Stable identifiers

- Experience: `EXP-0001`
- Fact: `FACT-0001`
- Evidence: `EV-0001`

Never recycle an identifier. A revision may retire an item but must preserve its historical ID.

## Evidence record

Capture:

- Evidence ID
- Source type
- Source path or user-confirmed provenance
- Date or date range
- Which facts it supports
- Sensitivity

Do not copy secrets, private credentials, cookies, or confidential employer content into the vault.

## Experience completeness

For each experience, capture:

- Organization, title, dates, and location
- Situation and objective
- Personal ownership
- Actions and decisions
- Constraints and trade-offs
- Collaborators and scope
- Outcomes and measurement method
- Skills demonstrated
- Evidence references
- Remaining uncertainty

Distinguish team outcomes from the user's own contribution. Do not transform approximate metrics into exact ones.

## Revision rule

Before creating a revision:

1. Show the exact changed IDs.
2. Show added, removed, and modified text.
3. Show changed evidence links.
4. Resolve contradictions or preserve both versions as an explicit conflict.
5. Obtain user approval.
